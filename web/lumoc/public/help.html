LUMO · 隧光

LUMO 是什么

LUMO 由两部分组成：服务端 lumos 装在有公网 IP 的服务器上，客户端 lumoc 装在内网设备（NAS、路由器、办公电脑）上。客户端主动连向服务端建立隧道，把内网里的服务「搬运」到公网——内网不用开任何入站端口。

示例图 1 · 流量走向：外网用户访问公网入口，经加密隧道到达内网服务

三步上手

  1. 拿令牌：登录服务端控制台 →「认证令牌」→ 生成并复制（令牌只在生成时显示一次）。
  2. 建配置：客户端控制台 →「新建连接配置」→ 填服务器地址与服务端口，粘贴令牌。
  3. 加映射：在配置里添加端口映射，如 127.0.0.1:5000 → 15000，保存并打开开关。

端口映射怎么填

本地地址是内网里真实服务的地址；公网入口是外网访问时用的端口（HTTP/HTTPS 类型填域名）。保存后，访问 http://服务器IP:公网端口 就等于访问内网那条本地地址。

安全建议

  • TLS 传输加密保持开启（连接配置里默认开启）。
  • 敏感服务不要用普通 TCP 暴露公网，改用 sealed-tcp / sealed-udp：凭密钥连接，公网上没有入口。
  • 给两个控制台都开启 2FA；认证令牌只在生成时显示一次，换设备需重新生成。
  • 服务端可设置「允许端口段」，限制客户端能占用的公网端口范围。

常见问题

外网访问不通？
① 看服务端控制台「代理与客户端」，对应代理显示在线；② 确认云服务商的安全组放行了该公网端口（LUMO 只能改系统防火墙，改不了云安全组）；③ 映射的本地地址在内网设备上先确认能打开。
动态码（2FA）丢了，登不进控制台？
在设备上删除密钥文件后重启进程即可重置：客户端是容器内 /data/console-totp.json；服务端是 /opt/lumo/lumos.toml 里的 totpSecret 行。重置后可重新绑定。
提示端口被占用？
同一公网端口同一时间只能属于一条映射。换一个端口，或在服务端控制台停掉占用它的旧代理。
连接频繁掉线？
客户端会自动重连（约 5 秒）。若持续掉线，检查内网设备到服务端的网络质量；不稳定链路建议切到 KCP（UDP）传输。

反馈渠道

提交反馈请到 GitHub Issues。为方便定位，请附上：

  • 版本号（登录页底部，如 v0.1.0）
  • 现象描述：做了什么、预期是什么、实际是什么
  • 日志：客户端控制台「运行日志」页可一键复制
日志里不含令牌与密码，可以放心粘贴；涉及内网地址时自行打码即可。
